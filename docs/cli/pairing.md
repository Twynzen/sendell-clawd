# `sendell pairing`

Approve or inspect DM pairing requests (for channels that support pairing).

Related:
- Pairing flow: [Pairing](/start/pairing)

## Commands

```bash
sendell pairing list whatsapp
sendell pairing approve whatsapp <code> --notify
```
