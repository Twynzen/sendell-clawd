# `sendell setup`

Initialize `~/.sendell/sendell.json` and the agent workspace.

Related:
- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
sendell setup
sendell setup --workspace ~/sendell
```

To run the wizard via setup:

```bash
sendell setup --wizard
```
